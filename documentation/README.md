# Documentation Fairest One

Journal de conception et de fabrication du prototype Fairest One, construit avec Docusaurus.

## Installation

```sh
npm install
```

## Développement

```sh
npm start
```

Le site est servi sous `/Fairest-One/`.

## Vérifications

```sh
npm run typecheck
npm run build
```

## Ajouter des médias

Placer les photographies et captures dans `static/img/`, puis remplacer les blocs d'attente dans les pages de `docs/`.

Ne documenter que les étapes, mesures et difficultés réellement rencontrées pendant la fabrication.
