# Construire Fairest One

Fairest One est un projet étudiant de Master 2 autour de l'IoT et des systèmes embarqués. Le prototype prend la forme d'un miroir connecté destiné aux opticiens.

Le parcours envisagé associe une adresse e-mail à une carte RFID/NFC. Devant le miroir, le client présente sa carte, déclenche une séquence de prise de vue et peut ensuite retrouver ses photos depuis une borne.

## Architecture envisagée

```text
Application Flutter <-> Backend / API <-> ESP32
```

Les communications pourront évoluer entre HTTP/REST, WebSocket ou MQTT. Le choix définitif n'est pas encore arrêté.
